Welcome to choppy orc!

Choppy orc is a 2D puzzle-platformer game where you control an orc with an axe. 
Your goal is to open all chests in every level and make it to the end of the game.
When you beat the game, you score is saved with a username in the "highscores.txt" file.

Controls:
WASD or Arrow keys: Move left, right, and jump
Spacebar: Throw/recall the axe
Mouse: Click menus and buttons

How do I run the game?
***Make sure to have the latest version of python and pygame installed***
Open the "Choppy Orc" folder in Visual Studio Code
Run the "main.py" file
